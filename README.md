# DexRoam project page

A static, responsive research project page for **DexRoam: Learning Mobile Bimanual Dexterous Manipulation from Egocentric Whole-Body Human Demonstrations**.

## Preview locally

From this directory, run any static file server, for example:

```powershell
python -m http.server 8000
```

Then open `http://localhost:8000`.

The site has no build step and uses only relative paths, so it can be served directly by GitHub Pages.

## Content

- `index.html` — page structure and paper content
- `assets/css/styles.css` — responsive visual system
- `assets/js/main.js` — navigation, method tabs, results toggle, lightbox, and citation copy behavior
- `assets/images/` — figures rendered from the paper source
- `assets/paper/dexroam.pdf` — downloadable paper
